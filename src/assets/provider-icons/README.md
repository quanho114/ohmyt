# Provider icon sources

The provider cards use company marks when the provider is a company and product marks when the catalog entry names a product. Icons are bundled locally so the settings page works offline.

| Catalog entry | Mark used | Source |
| --- | --- | --- |
| Anthropic Claude | Current Anthropic AI mark | [Anthropic site webclip](https://cdn.prod.website-files.com/67ce28cfec624e2b733f8a52/67d31dd7aa394792257596c5_webclip.png). |
| Google Gemini | Current Gemini sparkle | [Gemini official favicon](https://www.gstatic.com/lamda/images/gemini_sparkle_4g_512_lt_f94943af3be039176192d.png); Google announced the updated Gemini spark colors in its [brand update](https://blog.google/company-news/inside-google/company-announcements/gradient-g-logo-design/). |
| OpenAI | OpenAI Blossom | [OpenAI design guidelines](https://openai.com/brand/); inline vector follows the Simple Icons OpenAI mark. |
| DeepSeek | DeepSeek whale | Compared with [DeepSeek's official favicon](https://www.deepseek.com/favicon.ico); inline vector follows the Simple Icons DeepSeek mark. |
| Ollama (Local) | Ollama llama | [Official Ollama logo in its repository](https://github.com/ollama/ollama/blob/main/docs/ollama-logo.svg); inline vector follows the Simple Icons Ollama mark. |
| Moonshot AI | Moonshot company mark | [Moonshot AI site](https://www.moonshot.ai/en) publishes the favicon bundled here. |
| Amazon Bedrock | Bedrock service icon | [AWS architecture icons](https://aws.amazon.com/architecture/icons/), package dated 2026-07-31. |
| Xinference | Xorbits mark | [Official Xinference repository asset](https://github.com/xorbitsai/inference/blob/main/assets/xorbits-logo.png). |
