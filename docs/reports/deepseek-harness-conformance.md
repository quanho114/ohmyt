## Luồng authoritative hiện tại

```text
createDaemon → AgentLoop.run → AgentRegistry.execute / AgentHandle.run
  → ctx.agentLoop.run → legacyDriver → executeTurn (driver.js)
  → admission transaction + SessionStore.begin
  → createRunScope + filtered runTools + deterministic SystemPrompt
  → SessionStore.modelHistory → context selection
  → HarnessHost.request → compaction / prepareRequestEnvelope / RequestAttempts
  → committed assistant tool calls → batch prevalidation / schedule
  → HarnessHost.invokeTool → ToolInvocationService
  → authorizeTool → guards → Cordis tool middleware → body
  → canonical receipt → driver model observation + SSE
  → SessionStore.completeTurn transaction → RunCompleted / RunFailed
  → child drain + invocation drain + browser release + ownership release
```

`AgentLoop._run` và `legacyDriver` cùng gọi `executeTurn`, không phải hai loop độc lập. Production browser delegation và PTC subcalls đi qua invocation service. Standalone `AgentLoop`/`BrowserIntegration` adapters còn cần cho compatibility/tests; không xóa khi chưa chứng minh replacement. Browser planner có model subloop bounded sẵn; cần thống nhất admission/accounting của request đó, không tạo orchestration framework khác.

## Đánh giá prompt và plan cũ

Master prompt có đúng ranh giới: một runtime, một permission engine, SQLite hiện tại, incremental verification, DeepSeek là reference chính. Tuy nhiên 11 phases trộn bugs đã biết, parity và tính năng sản phẩm; không nên thực hiện thành một khối hoặc tuần tự máy móc.

Plan A/B/C cũ đã hiện diện trong HEAD: canonical invocation, semantic migration, plugin ownership, request envelope và offline acceptance có implementation/tests thực. Tài liệu validation cũ ghi baseline khác và “uncommitted”; thông tin ấy là lịch sử của lần chạy cũ. Không dùng nó để suy ra workspace hiện tại chưa triển khai A/B/C, hoặc để bỏ qua baseline failure mới.

Phạm vi đợt đầu nên giới hạn F1–F5; F6–F8 là đợt tiếp theo sau gate. Goal rounds, general planner, rolling pool optimization, dynamic plugin runner và UI restyling chưa cần thiết để sửa correctness.
